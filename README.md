# LMS Carlo Acutis

Web React + TypeScript + Vite cho Xứ Đoàn Carlo Acutis - Giáo Xứ Thăng Long.

## Chạy trên máy

Cài Node.js (khuyến nghị Node 20+), sau đó mở Terminal tại thư mục dự án:

```bash
npm install
npm run dev
```

Mở địa chỉ Vite hiện ra, thường là:

http://localhost:5173

## Đóng gói để đưa lên hosting

```bash
npm run build
```

Thư mục `dist/` là bản web đã build.
